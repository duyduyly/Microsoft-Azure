### What is Microsoft Azure?
- Microsoft Azure is a cloud computing platform and set of services provided by Microsoft. It lets you build, deploy, and manage applications and infrastructure through Microsoft-managed data centers worldwide.

#
### Key Concept
| Concept                                | Description                                                                             |
|----------------------------------------|-----------------------------------------------------------------------------------------|
| **Cloud Computing**                    | Using remote servers (instead of your own hardware) to store, manage, and process data. |
| **IaaS** (Infrastructure as a Service) | Rent virtual machines, storage, and networks. You manage the OS and apps.               |
| **PaaS** (Platform as a Service)       | Azure manages everything except your code. You focus on building apps.                  |
| **SaaS** (Software as a Service)       | Fully managed apps (e.g., Microsoft 365, Dynamics). You just use the app.               |

### What Can You do with Azure?
| Area                           | Services / Use Cases                                                                                |
|--------------------------------|-----------------------------------------------------------------------------------------------------|
| ☁️ **Compute**                 | Run apps using **VMs**, **App Services**, **Azure Kubernetes**, or **Azure Functions** (serverless) |
| 🧠 **AI & Machine Learning**   | Use **Cognitive Services**, **Azure OpenAI**, and **ML Studio**                                     |
| 📦 **Storage**                 | Store files, blobs, tables, or databases (SQL/NoSQL)                                                |
| 🧬 **Databases**               | **Azure SQL**, **Cosmos DB**, **MySQL**, **PostgreSQL**, **Redis**                                  |
| 🔔 **Messaging & Integration** | **Service Bus**, **Event Grid**, **Logic Apps**, **API Management**                                 |
| 📡 **Networking**              | Build VNETs, load balancers, firewalls, and use CDNs                                                |
| 🛡️ **Security & Identity**    | **Azure AD**, Key Vault, Role-Based Access Control (RBAC)                                           |
| 🧮 **DevOps & Monitoring**     | Azure DevOps, GitHub Actions, Monitor, Application Insights                                         |

#
### Service in Azure You Might Use?
| Azure Service         | Purpose                                         |
|-----------------------|-------------------------------------------------|
| `Azure App Service`   | Run web apps (Java, .NET, Python, Node)         |
| `Azure Functions`     | Run small pieces of code on-demand (serverless) |
| `Azure Blob Storage`  | Store images, videos, backups, etc.             |
| `Azure Service Bus`   | Handle messaging between microservices          |
| `Azure Cosmos DB`     | Globally distributed NoSQL database             |
| `Azure Table Storage` | Key-value table for structured data             |
| `Azure Monitor`       | Logging, metrics, alerts for your app           |
